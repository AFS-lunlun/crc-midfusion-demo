# Mid-fusion Demo

Browse-only Streamlit prototype.

- Test set n=42: predictions, survival curves, 24-month risk, reclassification
- Case 1–3: dose slices and Grad-CAM

## Run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app_mid_fusion_demo_tte_d.py
```

Streamlit Cloud main file: `app_mid_fusion_demo_tte_d.py`
